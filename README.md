Ethical AI project from Udacity: fairness and bias analysis using IBM AIF360, interpretability, and a model card.

Setup with [uv](https://docs.astral.sh/uv/): `uv venv && source venv/bin/activate && uv pip install -r requirements.txt`

Then start JupyterLab with: `jupyter lab` and open `AI Ethics Project -- STARTER.ipynb`.

The dataset is not included. Place `udacity_ai_ethics_project_data.csv` in this directory before running.
